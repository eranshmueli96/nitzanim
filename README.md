# שירים גן ניצנים

אתר סטטי עם נגן השירים של הגן. מתארח ב-GitHub Pages.

## מבנה

- `index.html` — כל האפליקציה (רשימה, חיפוש, קטגוריות, מסך נגן)
- `songs.json` — הספרייה. כל שיר: `id`, `name`, `category`, `file`, `seconds`
- `audio/` — קבצי ה-MP3 (96 kbps סטריאו)
- `manifest.webmanifest` + אייקונים — מאפשר "הוספה למסך הבית"

## הוספת שיר

1. להוסיף שורה ל-`SONGS` ב-`build_site.py` (מזהה באנגלית, שם בעברית, קטגוריה)
2. להריץ את הסקריפט — הוא מקודד רק את החדשים ומעדכן את `songs.json`
3. `git add -A && git commit -m "add song" && git push`

העמוד מתעדכן תוך כדקה. הקישור לעולם לא משתנה.
